# Reproducibility package

Code, deterministic configurations, tests, ledgers, identifiers, fold-level outputs
and derived numerical materials for *Screening-Off Information and Conditional Risk
in Portfolio Choice* (submitted to *Quantitative Finance*). The package reflects the
submitted version of the paper only.

## Data sources and access

Three licensed sources were used. They are not redistributed, and this package
contains no series (prices, returns, index levels or transformed drivers) from
which they could be reconstructed. Everything else needed to replicate the paper
is included; a researcher with authorized access to the three sources can
reproduce every reported number by following the order below.

- **Equity prices**: daily end-of-day close prices for the 150 tickers listed in
  `data/panel_b_fixed_universe.csv`, obtained from Tiingo (https://www.tiingo.com/).
- **Candidate drivers**: 127 economic and financial series (PX_LAST) obtained from
  Bloomberg. Identifiers, economic class, approved transformation, coverage and
  availability rules are in `extended_results/driver_ledger_bloomberg_px_last.csv`
  (equity calendar) and `data_lag0/driver_ledger_pilot.csv` (development panel).
- **Hedge-fund indices**: monthly returns of 17 BarclayHedge hedge-fund strategy
  indices (https://www.barclayhedge.com/), January 1997 to December 2025.

Place the source files in a directory outside this package (`--raw-dir`): a Tiingo
price export for the fixed universe, the Bloomberg driver workbook
(`Drivers_Assets_Dataset.xlsx`) and the BarclayHedge workbook (`HF_data.xlsx`).
The controlled experiments require no external data.

### Conditioning representation for the covariance experiment

The covariance experiment does not re-select drivers on the 150-stock panel. For
each fold it uses the most recent frozen selection, certified before the fold's
training end, produced by a same-date screening run on a separate 12-equity
development panel (102 eligible candidates, 504 selection and 252 certification
sessions, 126-session test blocks, penalty 0.01, at most eight drivers, 38 rolling
folds from 2002). That ledger is `development_panel/panel_a_fold_ledger.csv`; it is
regenerated by `scripts/run_panel_a.py` from the development-panel returns and
driver innovations built with `scripts/build_driver_panel.py --lag 0`.

## Reported empirical samples

- Equities: 150 tickers, 3,247 synchronous daily log-price-return dates from
  2 July 2010 to 30 June 2023; 3,196 complete observations for screening and 3,191
  for the covariance benchmark after the driver-alignment step of each exercise.
- BarclayHedge indices: 17 monthly series, January 1997 to December 2025; 269
  complete observations after driver alignment.
- Candidate drivers: 123 eligible series on the equity calendar and 119 on the
  monthly calendar after the frozen transformation and coverage rules.

Positive price and index levels are transformed to log changes; yields and rates
are first-differenced. Declared sentinels are treated as missing. A last observation
may be carried across at most three source rows before transformation; longer gaps
remain missing. Documented split-like stock-price discontinuities are adjusted,
reviewed distribution dates are excluded, and missing prices are not bridged.

## Reproduction order

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/reconstruct_panel_b_returns.py --raw-prices <tiingo_prices> \
  --fixed-universe data/panel_b_fixed_universe.csv \
  --event-ledger config/panel_b_event_ledger.csv --output-dir data
python scripts/build_driver_panel.py --workbook <raw>/Drivers_Assets_Dataset.xlsx \
  --output-dir data_lag0 --lag 0
python scripts/run_panel_a.py --asset-returns data_lag0/panel_a_asset_log_returns_common.csv \
  --driver-innovations data_lag0/driver_innovations_lag0.csv --output-dir development_panel
python scripts/run_extended_experiments.py --raw-dir <raw>
python scripts/run_extended_inference.py
python scripts/run_panel_b.py --asset-returns data/panel_b_log_price_returns.csv \
  --driver-innovations data_lag0/driver_innovations_lag0.csv \
  --panel-a-folds development_panel/panel_a_fold_ledger.csv --output-dir results_panel_b
python scripts/run_inference.py --panel-b results_panel_b/panel_b_fold_results.csv \
  --output-dir results_inference
python scripts/verify_release.py
```

Random seeds, transformations, fold boundaries, model-size limits, penalties and
multiplicity adjustment are fixed in code and configuration.
`extended_results/extended_inference.csv` and `results_panel_b*/panel_b_summary.csv`
contain the exact values reported in Sections 4.7 and 4.8.
